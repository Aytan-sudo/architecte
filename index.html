Notice de chantier

Construire le détour

Tous les autres jeux vous demandent de résoudre ce qu’une machine a posé. Ici, c’est l’inverse : vous construisez, la machine résout après vous.

01
Poser

Tapez une case libre : un mur s’y pose. Retapez-la : il repart. Rien d’autre à apprendre.

02
Regarder

À chaque pose, le plus court chemin de l’entrée à la sortie est recalculé et redessiné. Sa longueur est votre score.

03
Allonger

Le but est de rendre ce chemin le plus long possible en ayant posé tous vos murs.

04
Ne jamais fermer

Un mur qui rendrait la sortie inatteignable est refusé : la case recule, et votre budget reste intact.

Le meilleur connu

Le troisième chiffre est le meilleur résultat qu’une recherche automatique a su trouver sur cette grille. Ce n’est pas l’optimum : personne ne le connaît. Si vous faites mieux, vous avez battu la machine — et le jeu vous le dira.

Les variantes

Dans les Options, deux règles supplémentaires, qui se combinent :

◇
Stations

Le chemin doit desservir trois cases marquées d’un losange avant d’atteindre la sortie. Un mur qui allonge un segment peut en raccourcir un autre.

≡
Double ligne

Deux liaisons se croisent sur le plateau, et le score est leur somme. Chaque mur devient une négociation entre les deux. À partir de 16 × 16.

Le défi du jour reste toujours canonique : c’est ce qui rend les scores comparables d’un joueur à l’autre. Les variantes se jouent en partie libre, avec leurs propres records.

Plusieurs chemins

Quand plusieurs chemins font la même longueur, un seul est tracé et les autres apparaissent en pointillés. C’est pourquoi le tracé saute parfois d’un côté à l’autre après une pose sans rapport : ce n’est pas un défaut, c’est le même score par un autre passage.
